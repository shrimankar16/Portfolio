# 🪐 Space-Themed Portfolio — Shrijay Mankar

A single-page, hyper-realistic, animated **space-themed portfolio** built with
Next.js (App Router), React Three Fiber, Framer Motion, and TailwindCSS. It
showcases work split into **Web Development** and **Data Science**, and includes
a **one-time setup/onboarding flow** that pulls your real GitHub repos, reads
your GitHub profile README, and lets you paste LinkedIn post text to seed extra
skill tags.

---

## Tech stack

- **Framework** — Next.js 16 (App Router)
- **3D / space visuals** — Three.js via React Three Fiber + drei
- **Animation** — Framer Motion, CSS keyframes
- **Styling** — TailwindCSS v4
- **Data source** — `projects.config.json` (generated by the setup flow)
- **Deploy** — works on Vercel / Netlify (static-compatible; config is read at
  build/request time, so re-run the build after changing the config)

## Setup / Onboarding flow (run once)

Open **`http://localhost:3000/setup`** (this is a local admin page — visitors
never see it).

1. **GitHub username** — enter your username and click *Fetch repos*. The app
   calls the GitHub REST API and lists all your public repos.
2. **Select projects** — every repo is shown with an auto-suggested category
   (Web Dev / Data Science / Other) using the classification rules below. Check
   the ones you want to feature, fix any wrong category, optionally click
   *Fetch READMEs for selected* to enrich descriptions, then continue.
3. **Profile README** — the app auto-checks for the special `{username}/{username}`
   repo. If found, it pulls the README and suggests skill tags for your About
   section. Keep/remove any of them.
4. **LinkedIn** — paste your LinkedIn profile **URL** (used only as a Contact
   link — it is **never scraped**; LinkedIn has no public API). Optionally paste
   text from posts you want reflected; click *Extract skills* to get suggested
   skill tags to confirm/edit.
5. **Review & Save** — review your profile info, then **Save**. This writes
   `projects.config.json`. Reload `/` to see your updated portfolio.

> Your personal access token (optional) is used only in-memory to raise the
> GitHub rate limit while fetching — it is **never written** to the config.

---

## Adding a GitHub token (higher rate limit)

The GitHub API allows ~60 unauthenticated requests/hour per IP. For faster /
live re-fetching, paste a **fine-grained or classic personal access token** into
the *Personal Access Token* field on the setup page (Step 1). It is kept in
component state only. Create one at https://github.com/settings/tokens (public
repo read scope is enough).

---

## Re-running project selection later

When you add new repos, simply open `/setup` again and re-run the flow. The
page **prefills** from the existing `projects.config.json`, so you only need to
re-fetch and adjust. Save again to regenerate the config, then rebuild/redeploy.

---

## Updating pasted LinkedIn skill text

Open `/setup` → step **4. LinkedIn**, paste updated post text, re-run *Extract
skills*, confirm the tags, and save.

## Classification rules (Web Dev vs Data Science)

Applied in order, first match wins:

- **Data Science** — primary language is Python/R/Jupyter Notebook **and** the
  description/topics/README mention ML/data keywords (`machine learning`, `ml`,
  `data`, `pandas`, `numpy`, `tensorflow`, `pytorch`, `scikit`, `analysis`,
  `model`, `dataset`, `nlp`, `computer vision`, …).
- **Web Development** — primary language is JavaScript/TypeScript/HTML/CSS/PHP/Vue
  **or** topics contain `react`, `nextjs`, `frontend`, `backend`, `api`,
  `website`, `webapp`.
- If both match, the **per-repo language byte breakdown** decides the majority
  bucket.
- If nothing matches → **Other** (not featured by default).

These are **suggestions only** — you confirm/override every one in the setup UI.

## Performance & accessibility

- Lightweight **2D CSS starfield** fallback (no WebGL) used by default on mobile /
  low-end devices; a toggle (bottom-right) turns 3D effects on/off.
- The Three.js planet + starfield are **lazy-loaded** and only mount when 3D is
  enabled.
- Respects `prefers-reduced-motion` (disables 3D, scroll and CSS animation).
- Keyboard-navigable, labelled interactive elements, WCAG-AA-friendly contrast.

## Deploying

Build with the included command and host the `.next` output on Vercel/Netlify.

```bash
npm run build
```

Because the site reads `projects.config.json` at build/request time, **run the
setup flow before building**, or re-run `npm run build` after a config change so
the deployed site picks up the new data.
